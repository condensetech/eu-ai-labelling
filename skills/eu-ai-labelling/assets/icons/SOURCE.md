# EU Icon source

These are the official European Commission EU Icons for labelling AI-generated content, vendored unmodified (byte-for-byte copies). Only the file names were normalised.

- Icons page: https://digital-strategy.ec.europa.eu/en/policies/eu-icons-labelling-ai-generated-content
- SVG download: https://ec.europa.eu/newsroom/dae/redirection/document/129546
- Archive served: `LABEL_AI_GENERATED_SVG_LcQbQdw4Cnr30m5E8yzTgQZe8o_129546.zip` (SHA-256 `f76707b69b546677b173975c018528e5e549e12afb05550f32c2f46500ffbefd`)
- Retrieved: 2026-11-02

The PNG set the Commission also publishes is not shipped.

## Naming

`ai-<icon variant>-<icon colour>.svg`, where the Icon Variant is `basic`, `generated` or `modified`, and the Icon Colour is `black`, `white`, `black-50` or `white-50`.

The official files call the 50% colours "transparent": in them the pill's fill is at 50% opacity.
